# Голосовой ассистент

Telegram-бот для распознавания голосовых команд, поиска сотрудника в базе, переформулирования поручения и отправки сообщения в мессенджер и на email.

## Описание

Демонстрация MVP голосового ассистента для корпоративной коммуникации.

Сценарий работы:

```text
Голосовое сообщение
        ↓
Конвертация audio/ogg в audio/wav
        ↓
Распознавание речи через OpenAI Whisper
        ↓
Поиск имени сотрудника в тексте
        ↓
Сопоставление найденного имени с базой сотрудников
        ↓
Переформулирование поручения через ruGPT-2
        ↓
Отправка сообщения в мессенджер и на email
```

Пример голосовой команды:

> «Сообщи Кириллу Сотникову, что он должен занести документы»

Пример итогового сообщения:

> «Кирилл Сотников, занесите документы»

## Структура проекта

```text
.
├── bot.py              # основной файл Telegram-бота
├── config.py           # токены, данные сотрудников и настройки Gmail
├── staff.py            # извлечение имён и сопоставление с базой сотрудников
├── utils.py            # распознавание речи, генерация текста и отправка email
├── users.csv           # локальный журнал пользователей, запустивших /start
├── requirements.txt    # зависимости проекта
└── README.md           # описание проекта
```

## Основные компоненты

### `bot.py`

Главный файл проекта. Он запускает Telegram-бота и обрабатывает команды пользователя.

В нём реализованы:

- команда `/start`;
- регистрация пользователя в `users.csv`;
- приём голосового сообщения;
- скачивание голосового файла;
- конвертация `voice.ogg` в `voice.wav`;
- запуск распознавания речи;
- поиск сотрудника;
- генерация итогового поручения;
- отправка сообщения в Telegram;
- отправка сообщения на email;
- удаление временных аудиофайлов.

### `config.py`

Файл с настройками проекта.

В нём хранятся:

- `BOT_TOKEN` — токен Telegram-бота;
- `STAFF` — база сотрудников;
- `GMAIL_SENDER` — email отправителя;
- `GMAIL_PASSWORD` — пароль приложения Gmail.

### `staff.py`

Модуль для работы с именами сотрудников.

В нём выполняются две задачи:

- поиск имён людей в распознанном тексте через `spaCy`;
- поиск наиболее похожего сотрудника в базе через `fuzzywuzzy`.

### `utils.py`

Модуль вспомогательных функций.

В нём реализованы:

- загрузка модели OpenAI Whisper;
- распознавание аудиофайла;
- загрузка модели `sberbank-ai/rugpt2large`;
- генерация делового поручения;
- отправка email через SMTP Gmail.

### `users.csv`

Файл используется как локальный журнал пользователей, которые запускали команду `/start`.

Формат строки:

```text
chat_id;username;full_name
```

Пример:

```text
1980531189;Kiri_Bird;Кирилл
```

## Установка

Установите зависимости:

```bash
pip install -r requirements.txt
```

Дополнительно установите русскоязычную модель spaCy:

```bash
python -m spacy download ru_core_news_sm
```

Также на компьютере должен быть установлен `ffmpeg`, потому что бот конвертирует голосовые сообщения Telegram из `.ogg` в `.wav`.

## Настройка

Перед запуском нужно заполнить настройки в `config.py`.

Пример структуры:

```python
BOT_TOKEN = "your_telegram_bot_token"

STAFF = {
    "Иван Иванов": {
        "username": "ivan_ivanov",
        "chat_id": 123456789,
        "email": "ivan@example.com"
    }
}

GMAIL_SENDER = "your_email@gmail.com"
GMAIL_PASSWORD = "your_gmail_app_password"
```

Для Gmail лучше использовать не обычный пароль, а пароль приложения.

## Запуск

Запуск бота:

```bash
python bot.py
```

После запуска бот начинает слушать входящие сообщения через polling.

## Как пользоваться

1. Пользователь открывает Telegram-бота.
2. Нажимает `/start`.
3. Бот сохраняет пользователя в `users.csv`.
4. Пользователь отправляет голосовое сообщение с именем сотрудника и задачей.
5. Бот распознаёт речь.
6. Бот ищет сотрудника в базе.
7. Бот формирует деловое поручение.
8. Бот отправляет сообщение сотруднику в Telegram и на email.
9. Пользователь получает уведомление о результате отправки.

## 🧠 Как работает обработка голосовой команды

### 1. Получение голосового сообщения

Бот принимает голосовое сообщение Telegram и скачивает его во временный файл:

```text
voice.ogg
```

### 2. Конвертация аудио

Telegram присылает голосовые сообщения в формате `.ogg`. Для дальнейшей обработки файл конвертируется в `.wav`:

```text
voice.ogg → voice.wav
```

### 3. Распознавание речи

Функция `transcribe_audio()` из `utils.py` передаёт аудиофайл в модель OpenAI Whisper.

На выходе получается текст команды.

### 4. Извлечение имени сотрудника

Функция `extract_names()` из `staff.py` обрабатывает текст через spaCy и ищет сущности типа `PER`, то есть имена людей.

### 5. Сопоставление с базой сотрудников

Функция `find_best_match()` сравнивает найденные имена с ключами из `STAFF`.

Для сравнения используется `fuzz.partial_ratio()`.

Бот выбирает сотрудника с самым высоким совпадением.

### 6. Переформулирование поручения

Функция `generate_direct_command()` отправляет распознанный текст в модель `sberbank-ai/rugpt2large`.

Модель должна преобразовать исходную команду в короткое деловое поручение.

### 7. Отправка в Telegram

Если у сотрудника в `STAFF` указан `chat_id`, бот отправляет ему итоговое сообщение.

### 8. Отправка на email

Если у сотрудника указан `email`, бот формирует письмо и отправляет его через Gmail SMTP.

### 9. Очистка временных файлов

После обработки бот удаляет временные файлы:

```text
voice.ogg
voice.wav
```

## 📝 Что и куда логируется

В текущей версии проекта нет полноценного отдельного лог-файла. Логирование сделано простым способом.

### `users.csv`

В файл `users.csv` записываются пользователи, которые нажали `/start`.

Сохраняются:

- `chat_id`;
- `username`;
- имя пользователя.

Это нужно, чтобы знать, какие пользователи уже взаимодействовали с ботом.

### Консоль

В консоль выводятся служебные сообщения:

- новый пользователь зарегистрирован;
- пользователь уже был зарегистрирован;
- ошибка отправки email.

### Telegram-ответы пользователю

Часть статусов отправляется прямо пользователю в Telegram:

- сообщение отправлено сотруднику;
- не удалось найти сотрудника;
- ошибка отправки в Telegram;
- email успешно отправлен;
- email не удалось отправить;
- email сотрудника не указан.

### Временные файлы

Во время обработки создаются временные аудиофайлы:

```text
voice.ogg
voice.wav
```

После обработки они удаляются.

### Чего пока нет

В текущей версии не сохраняются в отдельный лог-файл:

- распознанный текст;
- найденный сотрудник;
- итоговое сообщение;
- время обработки;
- статус каждого этапа;
- ошибки распознавания;
- история отправленных поручений.

Для дальнейшего развития можно добавить файл `logs.csv` или полноценную базу данных SQL.

Пример будущей структуры логов:

```text
datetime;user_chat_id;recognized_text;matched_employee;command;telegram_status;email_status;processing_time
```

## Ограничения текущей версии

Текущая версия является MVP-прототипом.

Ограничения:

- база сотрудников хранится прямо в `config.py`;
- нет отдельной базы данных;
- нет полноценного логирования всех этапов;
- при выборе сотрудника всегда берётся лучшее совпадение;
- нет порога уверенности;
- нет уточняющего вопроса при неоднозначном имени;
- модель генерации может иногда выдавать нестабильный текст.
